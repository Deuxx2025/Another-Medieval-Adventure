# Another Medieval Adventure

Welcome to my personal project, this is something that I decided to do when I was taking a break from university since I'm studying games development I got in love on the programming aspect and also on creating something of my own, I've done games in Lua using LOVE2D, also web browser games using JavaScript, Node.Js for the back-end server, Phaser for the front-end of the game and also using DataBases in SQL, finally I'm doing a Unity 2D game using C#. 

## How it all started

I was jobless and with nothing else to do but I still call my best friend and withing the conversation I jokingly said that it would be nice if you teach me how to do a mathematics grade document and I'll teach him how to make a game, originally I was going to teach him how to use Lua but my friend didn't want to suffer making a game in that engine so we decided to go to Unity. 

We created a Game Design Document and then proceeded to make the game.

## About the game

This is an RPG (or at least try to be an RPG) were the player has the ability to choose the main character of the adventure, right now there are only 3 characters available and also for testing reasons there is only `1` main character, once the player chooses the main character the other 2 characters will become followers, also the player can choose a rune for the skill, in the far future there is going to be a skill tree but right now all runes do the same and the "skill tree" is hard coded since it has the same behavior. 

There are 2 states on the game right now, a roam free state where the player can explore the world (rooms in this case) getting items and solving puzzles to advance in the game, once the player solves the puzzle the next room is full of enemies and it will enter onto the 2nd state which is the Combat, I'm currently working in the combat and my friend is working on the roam-free part of the game. 

I'm publishing the source code of the project because I want people to see how we did this game, to be honest I do want to keep working on this but I don't know how to make money with this since the source code is uploaded for everybody to build for free but that's a problem for future me.
